## 되돌리는 법

거의 전부 **그 한 줄을 False 로** 두면 된다. 값이 숫자인 것은 이렇다.

- 신호 가중 → `SIG_WEIGHT` 를 전부 0.0
- 교차 짝 → `CROSS_PAIR_ENABLED = False`
- 조합 수 상한 → `COMBO_CAP_ENABLED = False` (저배당만 남기려면 `COMBO_CAP_LOW_ONLY = True`)
- 중고배당 복원 → `_EV_RESCUE_MAX = 0`
- 기대값 문턱 → `EV_MIN_ENABLED = False` (그러면 전 종목 1.0 으로 돌아간다)
