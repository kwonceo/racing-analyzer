# 기각 이력 (rejected)

## 이 문서는 무엇인가
**시도했다가 기각된 안**을 남긴다. 없으면 **같은 안이 다시 나온다.**

### 🔴 필수 5필드
| # | 필드 | 왜 |
|---|---|---|
| 1 | **무엇을 시도했나** | 안의 내용 |
| 2 | **왜 그럴듯했나** | 🔴 이게 없으면 같은 안이 또 나온다 |
| 3 | **어떻게 기각됐나** | 판정 방법 |
| 4 | **숫자** | ⚠ 분모를 반드시 명시 |
| 5 | **상태** | 기각 확정 / **잠정 기각**(분모 부족) |

⚠ **"잠정 기각"과 "기각 확정"을 구분한다.** 분모가 좁으면 잠정이다.

## 🟡 잠정 기각

### 왕축 복승 대안 — 축1 + 삼복승 3착마 (2026-07-31)

**① 무엇을 시도했나**
복승 추천이 1개뿐인 경주에서, 삼복승이 인정한 3착마를 축과 묶어
복승을 1개 더 추가한다. (예: 복승 `1+7` 만 있고 삼복승이 `1+5+7` 이면 `1+5` 를 추가)

**② 🔴 왜 그럴듯했나**
> **삼복승에서 5번을 3착 후보로 보면서 복승에서는 5번이 2착 안에 들 가능성을 안 보는 것이
> 일관성이 없다.** 같은 분석이 두 개의 다른 결론을 낸다.
- 실제로 아오모리 6R T-5.7분에 복승은 `2+7` **하나뿐**이었고 삼복승은 `1+5+7` 이었다.
- 추천 71.6%가 시장 최저배당을 추종하는 문제의 해법이 될 수 있어 보였다
  (대안은 중배당으로 간다 — 방향은 옳다).

**③ 어떻게 기각됐나**
T-5분 시점 `recommendation_history` 로 조건 충족 경주를 전수 추출해 리플레이.
**상위 1건·3건 제외**(원칙 2)에서 무너졌다.

**④ 숫자 (⚠ 분모 = 조건 충족 + 결과 확정 **95경주**)**
| | 값 |
|---|---|
| 현행 적중 | 34 / 95 = **35.8%** |
| 대안 적중 | 11 / 95 = **11.6%** |
| 추가분 회수율 (추가투자 116구좌) | **92.5%** |
| 🔴 상위 1건 제외 | **68.5%** |
| 🔴 상위 3건 제외 | **36.3%** |
| 배당 중앙 | 현행 2.4배 ↔ 대안 **28.5배** |
| 최상위 배당 | 27.8 · 20.2 · 17.2 · 13.5 · 11.7 |

- ⚠ **적중 11건 중 상위 3건이 전체의 61%** — 극단값 의존.
- ⚠ 투자가 **2.2배** 늘어난다(95 → 211구좌).

**⑤ 상태: 🟡 잠정 기각**
- ⚠ 분모 95경주. 마감시각(`deadline_epoch`) 미보유로 **486건 중 325건(66.9%)이 제외**됐다.
- ⚠ `out-of-sample` 기간 분할 · 배당 구간 분해 · 코드 경로 재현(`_lowodds_exempt`·EV·tier) **미실시**.
- ⇒ **분모 확대 후 재판정 예정.** 지금은 채택하지 않는다.

## 🟢 유효한 발견 (기각과 별개로 남는 것)

### ① 복승-삼복승 불균형은 **실재한다** (95경주)
복승 추천이 **1개뿐**이면서 삼복승 3착마가 복승에 **없는** 경주가 조건 충족만 95건.
- **답이 "그 3착마를 복승으로 사는 것"이 아닐 뿐, 구조는 문제다.**
- ⚠ 그리고 **복승이 1개뿐인 경주가 이만큼 있다**는 것은
  **회원이 걸 게 하나뿐인 경주가 상당수**라는 뜻이기도 하다. 별도로 볼 가치가 있다.

### ② "왕축 1.7배" 는 **코드에 없다** (2026-07-31 확인)
- 실제 코드 임계: **단승 2.0배**(`strongAxis`) · **복승 2.5 / 3.0배**(`_lowodds_exempt` 컷)
- `1.7` 은 검색해도 임계로 쓰이는 곳이 없다 → **대표 경험치**이며 **코드 영향은 0**.
- ⚠ 감으로 박힌 상수가 틀린 전례(`_EST_CAL 2.0` · `paceBonus` 방향 · EV 곡선 20.5배)와
  같은 유형이므로 **판정 기준으로 쓰지 않는다.**
