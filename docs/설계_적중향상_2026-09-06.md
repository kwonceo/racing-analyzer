> 대표: *「전적과 복기 분석을 중요하게 다뤄왔고 데이터를 충분히 쌓아왔는데 활용을 못하고 있어. 더 나은 분석과 적중을 위해 최적의 설계를 해줘」*

## 1. 왜 「더 잘 맞히기」 설계를 내지 않는가

같은 질문(「어떤 말이 오나」)을 **일곱 번** 다른 방법으로 물었고 일곱 번 같은 답이 나왔다.

| 날짜 | 방법 | 결과 |
|---|---|---|
| 7/29 | 전개 부스팅(`_scenario_plan`) | z=−2.80 **유의하게 나쁨** |
| 7/30 | 각질쌍 확률 테이블 461셀 → 재측정 | 생존 셀 0 · 음신호 0.485 도 표본 1.45배에서 **1.193 으로 뒤집힘** |
| 7/30 | 라인 축 | 엣지 1.068 · CI 하한 0.893 미달 |
| 8/28 | `record_score`(전적) 시장순위 고정 비교 | 22,552마 · **차이 없음** |
| 9/01 | 순수 능력 vs 시장 포함률 | **22.0% ↔ 52.1%**(한국 11.6%) |
| 9/01 | 다변량 2-way 461셀 OOS | 생존 16 → **전부 기준선보다 ROI 낮음** |
| 9/02 | 실패 유형 사전(마감 전 관측 12유형) | OOS 통과 2 · **둘 다 판정선 미달** |

🔴 **전적은 시장이 이미 다 반영했다.** 우리 유력마 상위3 포함률 47.3% ↔ 시장 53.8%(7/31). 전적을 더 섞을수록 나빠진다(8/24 기간 3분할 기각).
🔴 그리고 **입상률을 올리면 회수율이 내려간다**(9/01 · 원칙 14). 「더 잘 맞히기」는 저배당 복사로 수렴한다.
⇒ **적중률 자체를 목표 함수로 두지 않는다.** 목표는 **3제외 회수율 74.5% 초과 + 기간 3분할 통과 + 적중 30건**이다(판정 4단계 · 불변).

## 2. 설계 원칙 (전부 이미 실사고로 배운 것)

1. **판정선을 낮추지 않는다** — 3제외 74.5% · 적중 30 · 기간 3분할 · 종목별.
2. **그 시점에 있던 값만 쓴다**(원칙 27) — 모든 피처는 **T-5 동결값**. 마감 후 재계산 값은 입력 금지.
3. **기준선은 기간마다 낸다** — 9/01 실측 기준 입상률 48.4% ↔ 70.6%(22%p 표류). 절대값 비교 금지.
4. **측정 입력 = 실전 입력** — 도구와 실전이 같은 함수·같은 데이터를 읽는지 **코드로 대조**한 뒤 켠다(0-3 이 정확히 이 위반이다).
5. **오탐률을 재기 전엔 켜지 않는다**(원칙 20) · **켜면 계수기**(원칙 23) · **폴백은 센다**(원칙 24).
6. **회원이 받는 것과 재는 것을 같게**(8/29 `JUDGE_MATCH_MEMBER`) — 성적표만 좋아지는 변경 금지.

### B층 · 검증된 축의 **실전 기록 개시** 와 재판정 (시간 축)

- **B1** A1 적용 즉시 `logs/late_drop/<날짜>.jsonl` 에 **실전 발동·결과가 처음 쌓인다.** 이것이 소급 측정을 대체하는 **전향적 표본**이다.
- **B2** 🔴 0-5 를 정면으로 다룬다: 9월 경마 3제외 16.3%(적중 5). **9/15 재측정**(`--vary` · 문턱 고정)에 **기간 4분할**(8월 전·후반 · 9월 전·후반)을 추가한다.
  · 세 구간 이상에서 3제외 100% 미달이면 **이 축도 종결 후보**다. 판정선을 낮춰 살리지 않는다.
  · ④안(경주당 3개 · 5~80배) 확장은 그 결과를 본 뒤에만.
- **B3** 알림 문구는 그대로 「추가」다. 기존 추천을 지우지 않는다(8/28 설계).

### C층 · 쌓인 데이터의 용도 전환 — **말 예측이 아니라 「경주 선별기」**

> 질문을 바꾼다: 「어떤 말이 오나」 → **「이 경주에서 우리 명단을 사도 되나」**.
> 9/01·9/02 가 이미 그 방향을 가리켰다(집중도 축이 판정선까지 1.9%p · 틱 얕음 · 구좌 4개↑ 73.6%).

- **C1 재료** (전부 있다 · 새 수집 없음)
  · ML 학습셋 6,611행 · 피처 18(`max_drop_pct`·`drop_timing_min`·`reversal`·`smart_money`·`lead_count`·`pace_type`·`form_score`·`horse_count`·`gate_no`·…) + 라벨(`hit_place`·`odds_place`·`roi`)
  · 복기 1,241행(`observed`: mb·conc·horses / `member.sent` / `answerOdds`)
  · 실패사전의 **마감 전 관측 필드**(틱 수 · 집중도 · 두수 · 구좌 수 · 명단 폭)
- **C2 라벨** — 경주 단위 **「현행 명단(회원 수신)의 3제외 회수」**. 입상 여부가 아니다(원칙 14).
- **C3 방법** — 블랙박스 모델 금지(설명 안 되는 것에 판정 4단계를 못 건다). **T-5 관측값만으로 만든 셀**(2~3변수)을 `tools/mine_cross_cells.py` 방식으로 훑되, 목표 함수를 **회수율**로 바꾼다.
  · 출력은 **「사지 말 경주」 목록**이 아니라 **경주 신뢰도 등급**(🟢/🟡/🔴)이다 — 추천을 바꾸지 않고 **회원이 고르게** 한다(8/10 대표 결정 「표시만 제대로 하고 회원이 결정한다」와 같은 선).
  · 통과 기준: 🔴 등급 제외 시 나머지의 3제외 ≥ 74.5% **그리고** 🔴 등급 자체가 기간 3분할에서 일관되게 나쁠 것 **그리고** 🔴 비중 5~30%(원칙 18).
- **C4 정직한 기대치** — 9/02 회피 12유형 중 통과 2 · 둘 다 미달이었다. **이번에도 통과 0 일 수 있다.** 그래도 하는 이유: A2·A3 를 고친 뒤 처음으로 **오염 없는 입력**으로 재는 것이고, 실패해도 「경주 선별은 안 된다」가 확정된다.
- **C5 복기의 용도 재정의** — `전적오판 1,971건` 은 사후 유형이다(마감 전 못 쓴다). 복기는 **C3 의 라벨 공급원**(회원 수신 명단 · 정답 배당 · T-5 관측)으로 쓰고, `improvement` 문구(「더 사자」)는 **근거로 쓰지 않는다**(9/02 · 방향이 실측과 반대).

## 5. A1 패치 (준비만 · ⚠ 경주 없는 시간대에 적용 · 리로더가 재기동한다)

`_late_drop_alert` 에서 캐시 `history` 대신 **측정 도구가 쓰는 것과 같은 `odds_history` 스냅샷**을 읽는다. 오염 틱 제외 규칙은 도구(`measure_late_drop_sport.py`)와 동일하게 둔다.

```python
        # (전) hist = list(doc.get("history") or [])
        # 🔴 [2026-09-06] 캐시 history 틱에는 minutes_before 가 없어 picks() 가 전부 건너뛴다(6일간 fire 0).
        #   측정 도구와 **같은 입력**(odds_history 스냅샷)을 읽는다 — 원칙 5(측정 입력 = 실전 입력).
        _p, _, _ = _analysis_log_path(rk)
        _od = _hist_read_any(_p.replace(os.sep + "analysis_log" + os.sep, os.sep + "odds_history" + os.sep)) or {}
        hist = [t for t in (_od.get("snapshots") or [])
                if isinstance(t, dict) and t.get("minutes_before") is not None
                and not t.get("odds_suspect") and not t.get("baseline_reset") and not t.get("next_race_blocked")]
        if not hist:
            _gate_hit("late_drop_nomb", rk, "mb 있는 틱 0", reach_only=True)   # 원칙 24 — 폴백은 센다
            return
```
⚠ 적용 전 확인 2가지: ⓐ `_analysis_log_path(rk)` 가 튜플을 돌려주는지(8/27 사고) ⓑ 경로 치환이 실제 파일을 찾는지 — **오늘 경주 키 하나로 실데이터 호출**해 hist 길이가 0 이 아닌 것을 본 뒤에 저장한다.
⚠ 발송 대상은 `_kakao_send_to_me` 그대로다. 문구·상한·종목(`horse`) 무변경.
🔧 되돌리기: `LATE_DROP_ALERT_ENABLED = False` 한 줄(기존).
